## 决策闭环

1. **盯角度**：BSC meme 的“角度”来自 CZ/一姐/官推/马斯克等大号推文；他用监听工具和群消息第一时间捕捉
2. **查安全与筹码**：看前排地址是否内盘阴谋地址、是否捆绑、合约是否 fork 套路、黑客是否已清仓
3. **判叙事与文化**：判断 meme 有没有可延展的文化/理念（$scihub 知识自由、踏马、Freedom of Money），能否等到大号“助攻”
4. **小仓早进**：几百到一千多美元的小仓，在群里先发、市值早期进；不开杠杆
5. **翻倍出一半**：约 2 倍先卖一半回本，余仓“拿到上现货”或放着；卖飞和错过是常态
6. **复盘记账**：月度/事件复盘（1011、broccoli714、AST），公开“农了多少”

## 思维模型

- **MM-01 角度驱动律**：BSC 中文 meme 的需求端由 CZ/一姐/官推的“角度”决定；角度可延展才值得持有，有瑕疵就会失效。「BSC 上 meme 的角度主要依靠cz/一姐，还有官推的推文。」
- **MM-02 信息位时间差**：发现→发群→发推存在分层时间差，越靠后赔率越低；推特读者天然处在最后一层。「我 1.2M 时发在群里，已经50倍。」
- **MM-03 前排筹码体检**：前排是交易所钱包=筹码分散；前排是低余额内盘地址=阴谋盘。「top50几乎都是内盘的阴谋地址」
- **MM-04 翻倍回本+残仓**：约 2 倍卖一半回本，余仓变免费期权；残仓太少就吃不到尾部。「剩下一点不卖了，拿到上现货。」
- **MM-05 无杠杆生存律**：不开杠杆/合约/做空、不借钱、留 2–3 年生活费，用现金流换在黑天鹅中存活。「不开杠杆/合约/做空」
- **MM-06 黑客清仓反转**：黑客/大户清仓前不买；清仓后砸盘风险消失，叙事仍在时反而是机会。「黑客清仓前，买币要小心；但是卖出后，砸盘的风险就消失了」
- **MM-07 流程防骗**：损失多来自焦虑与偷懒：认准官网、逐位核对地址、交易机不装来源不明软件。「认准官推和官网，不要去点击可疑网站！」
- **MM-08 KOL 共振警报**：多个 KOL 同时喊同一项目，大概率是拿了项目方的钱，先警惕。「当很多kol同时提到一个项目的时候，你就需要警惕了」
- **MM-09 文化型 meme 有第二买家**：有现实受益方和理念的 meme 能吸引认同者作为第二批买家，回撤后有人接。「我对 $SCIHUB 文化的理解：信仰知识自由。」
- **MM-10 工具即信息位**：用 AI/脚本自建监控把“看到”的延迟降到最低；工具被平台内置后速度 edge 消失。「高频的还是要通过 API。」

⏱️ 研读约 7 分钟 · 📝 关联原推 26 篇

- 角度有瑕疵（敏感话题、删推）就会失效

**现象**：【角度来源】2026-01-05 他总结：「BSC 上 meme 的角度主要依靠cz/一姐，还有官推的推文。」并推演 dev 用推特 API 抢跑发币的流水线。2025-11-08 他提出边界：「我建议 cz 和一姐助攻 meme 到上币安就足够」。【角度失效】2026-01-21 解释一姐删推：「一姐也是想给P小将助攻的，但怎奈这个角度有瑕疵。」【自造角度】2026-01-17 讲踏马时列角度：「踏马（TM）是中文最流行的语气助词」。

**机制**：【因果】BSC 中文 meme 的最终买家是“相信大号会再提一次”的散户，所以大号推文是需求端的唯一强催化；角度可延展（马年、回购次数）时，持有者有理由等下一次助攻。【漏洞】角度是公开信息，dev 和机器人比人快（他自己 2026-01-05 就描述了抢跑流水线），所以“看到角度再买”天然处在信息链后端；他没说清楚普通人在什么时间窗口还有赔率，档案里没谈过具体市值区间。

**规则**：
- 如果一个币的唯一叙事是“等 CZ/一姐提”，就只给 1% 试仓
- 如果角度涉及敏感话题，就预期删推风险，不加仓
- 如果同一角度 1 小时内出现多个同名 ca，就只看已有聪明钱的那一个

**过滤**：
- 过滤他对 cz/一姐的“建议”类推文：观点不是信号
- 过滤依赖他与币安关系才能拿到的信息（活动、面谈）
**护栏**：临场抢跑：看到大号推文后强制等 3 分钟再看图，3 分钟内不点买入，防止买在机器人出货点。

**局限**：他与币安生态关系密切（多次参加币安活动、简介挂币安钱包邀请），对 cz/一姐的解读有立场。角度论只适用于 BSC 中文 meme；2026-01-05 他说角度“非常小”，与 2026-04-19 再列“meme能量排行”CZ 第三前后一致，但没有给出量化证据。
