# 摇卦

用三枚铜钱摇六爻的中文小站。记录只留在这台浏览器里。

仓库根目录仍是 KOL 档案馆，不要改那里的 `index.html`。摇卦是旁边这个独立应用。

## 本地打开

```bash
cd yaogua
npm install
npm run dev
```

浏览器打开终端里给出的本地地址。生产构建：

```bash
npm run build
npm run preview
```

## 怎么摇

1. 在首页把想问的事写下来，也可以留空。
2. 从初爻到上爻，摇六次。字为三，背为二。
3. 六是老阴，七是少阳，八是少阴，九是老阳。六和九是动爻。
4. 看本卦、动爻，以及动爻翻转后的之卦。

六十四卦可以按卦名或上下卦浏览。那是卦义速读，不是一次起卦。
